# 말뚝 간격 측정 (Pile Spacing Measure)

휴대폰 카메라로 찍은 사진 한 장에서 말뚝 사이 거리를 재는 웹앱입니다. 설치나 서버가 필요 없습니다.

- `index.html` — 그대로 열거나 웹서버(HTTPS)에 올려 쓰는 단독 실행 파일
- `app.html` — 같은 앱의 본문(Claude 아티팩트 게시용). 수정 후 `index.html`도 같이 갱신하세요.

## 카메라
`index.html`을 HTTPS 주소(또는 localhost)로 열면 **촬영하기**가 앱 안에서 실시간 카메라 화면을 띄웁니다
(후면 카메라 우선, 최대 4K, 전·후면 전환). 카메라를 막는 화면(예: Claude 아티팩트 안, 권한 거부)에서는
휴대폰 기본 카메라 앱으로 자동 전환됩니다.

## 원리
1. 말뚝과 같은 바닥면에 놓인 직사각형(예: 줄자로 잰 2 m × 2 m)의 네 꼭짓점을 찍으면
   사진 → 바닥 평면 호모그래피를 계산해 원근을 보정합니다.
   (수직으로 내려다본 사진이면 길이를 아는 두 점만으로도 됩니다.)
2. 각 말뚝의 **밑동(지면과 닿는 점)** 을 찍으면 바닥 좌표(m)로 변환해 연속 구간·모든 쌍의 거리를 계산합니다.
3. 1 m 격자를 사진 위에 겹쳐 보정이 맞는지 눈으로 확인하고, CSV·표시된 사진으로 저장할 수 있습니다.

바닥이 평평하다고 가정하므로 경사·요철이 크거나 기준에서 멀리 떨어진 말뚝은 오차가 커집니다.
